
# Python Programming Labs

Collection of programming exercises and practical assignments developed in **Python** as part of the Computer Engineering degree at the University of Alcalá (UAH).

This repository brings together laboratory exercises covering fundamental programming concepts, algorithm design, data structures and problem-solving techniques.

## Contents

The repository is divided into seven exercise notebooks and two practical assignments.

| Section | Topics |
|---|---|
| Cuaderno 1 | Variables, data types, operators and basic operations |
| Cuaderno 2 | Functions, mathematical operations, conversions and complex numbers |
| Cuaderno 3 | Conditional statements, decision-making and input validation |
| Cuaderno 4 | Iterative algorithms and loops |
| Cuaderno 5 | Lists, strings and data processing |
| Cuaderno 6 | Dictionaries and structured data |
| Cuaderno 7 | Recursive functions and algorithms |
| PECL1 | Practical programming exercises: patterns, prime numbers and sequences |
| PECL2 | Practical assignments and data simulation |

## Technologies and Tools

- **Programming Language:** Python 3
- **Development Environment:** Visual Studio Code
- **Version Control:** Git and GitHub

## Concepts and Skills

Throughout these exercises, several fundamental programming concepts are covered:

- Variables, data types and operators.
- Functions and modular programming.
- Conditional statements and loops.
- Input validation and exception handling.
- Lists, strings and dictionaries.
- Mathematical algorithms and numerical operations.
- Recursive problem-solving.
- Basic algorithm design and implementation.

## ⚙️ Getting Started

### Requirements

- Python 3.x
- A compatible code editor (such as Visual Studio Code).

### Running an exercise

Navigate to the directory containing the desired exercise and execute:

```bash
python ejercicio1.py
```

Replace `ejercicio1.py` with the name of the exercise you want to run.

Some exercises require user input through the terminal.
